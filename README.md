### 📌 About the Project

Interactive **HR analytics dashboard** built in Power BI, analyzing **1,000 employees** data — built for HR teams who need a clear, visual read on workforce performance, attrition trends, and salary insights, instead of digging through spreadsheets.

---

### 📊 Key Metrics

| Metric | Value |
|---|---|
| 👥 Total Employees | **1,000** |
| ✅ Active Employees | **808** |
| 📉 Attrition Rate | **19.20%** |
| 🎂 Avg Age | **40.32 Years** |
| ⭐ Avg Job Satisfaction | **3.02 / 5.0** |
| 🏢 Avg Years at Company | **3.27 Years** |

---

### ✨ Features

- 📉 Employee attrition analysis by department
- 🚻 Gender distribution breakdown
- 💰 Avg salary comparison by department
- 🏆 Performance rating distribution
- 🎛️ Interactive slicers (Department, Attrition, Gender)
- 🧮 DAX measures for KPI calculations
